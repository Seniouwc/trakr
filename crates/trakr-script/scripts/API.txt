trakr scripting (Lua 5.4)

A script edits a copy of the song. When it finishes without an error the whole run becomes one
undo step; on error nothing changes and the message is shown. Numbers for patterns, tracks, lines
and columns start at 0, like the editor shows them. No files, no OS access, no loading other code;
runs are limited in time and memory. The usual string, table, math, utf8 and coroutine libraries work.

Context (read-only)
  trakr.ctx.pattern, .seq_pos, .track, .line, .col, .instrument, .octave
  trakr.ctx.selection  nil, or { track0, track1, line0, line1 } (inclusive)

Song
  trakr.song()                      table: name, author, bpm, lpb, tpl, tracks, patterns,
                                    instruments, sequence (list of pattern numbers)
  trakr.set_song{ bpm=, lpb=, tpl=, name=, author= }   any subset
  trakr.track_name(t)  trakr.instrument_name(i)        nil if it does not exist

Patterns
  trakr.pattern_lines(p)            number of lines (nil if no such pattern)
  trakr.set_pattern_lines(p, n)     1..512
  trakr.add_pattern([lines])        returns the new pattern number
  trakr.append_to_sequence(p)
  trakr.clear_pattern(p)

Cells
  trakr.get_note(p, t, l, c)        { note, name, instrument, volume, panning, delay, fx }
                                    note: 0..119 (48 = C-4), 120 = OFF, 121 = empty;
                                    instrument/volume/panning/fx are nil when empty
  trakr.set_note(p, t, l, c, { note="C-4" or 48, instrument=1, volume=64, panning=64,
                               delay=0, fx="0A40" })
                                    fields you leave out stay as they are; false clears one
  trakr.clear_note(p, t, l, c)
  trakr.get_effect(p, t, l, c)      "0A40" or nil          (effect columns)
  trakr.set_effect(p, t, l, c, "0A40")   false clears

Helpers
  trakr.note_name(n)  trakr.parse_note("C-4")
  trakr.status("text")              message in the status bar
  trakr.play()  trakr.stop()        requested after the script ends
  print(...)                        goes to the console output
