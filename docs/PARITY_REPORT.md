# trakr vs Renoise: parity report

Scores are out of 10 and mean "how much of what a Renoise 3.x user relies on in this area works in trakr
today", not code quality. **Caveat:** the reference is my memory of Renoise 3.x behavior, not the official
manual or a side-by-side session, so treat scores as informed estimates. Command ids and `.xrns` element
names are unverified (see `docs/PARITY.md`, which lists every item).

Evidence base: about 36,000 lines of Rust in 16 crates and 335 automated tests (last full run green, clippy clean) (engine rendering and fuzzing,
editor operations and fuzzing, GUI input routing, file formats, a real CLAP test plugin loaded from disk,
sandboxed Lua). The GUI was driven live under a virtual display. **Not tested:**
real speakers or audio devices (device/host/buffer switching is only tested with a fake backend; JACK was never built), real third-party plugins and plugin windows, recording from a real microphone, a real MIDI keyboard, Windows/macOS, long
sessions, large songs.

## Scorecard

| Area | Score | Where it stands |
|---|---|---|
| Pattern editor and note entry | 7.1 | Notes, instrument, volume, pan, delay, effect columns; hex entry; selection, copy/cut/paste, transpose, reverse, interpolate, fade ramps, insert/delete line; unlimited-ish undo; add/remove tracks and columns; MIDI recording. Phrase editor (Phrases dock) and Lua scripts for bulk edits. Find/replace, randomize, expand/shrink/repeat block and a command palette. Mix paste, flood paste, per-track hiding of the volume, panning and delay sub-columns, volume/panning column letter commands and track colors also work. Missing: line highlight settings, track collapse and move, quick-select. |
| Song structure and sequencing | 7.4 | Sequence list (insert, clone, delete, move, pick pattern), pattern length and names, loop range, play song / pattern / from cursor, follow. Pattern matrix, named sections, per-slot track mutes, groove/shuffle, loop-a-block and song properties. Tempo and lines-per-beat automation lanes, section repeat counts and drag-and-drop of slots in the matrix work; exports carry the song's title and author as tags. Missing: arbitrary jumps (pattern jump commands), per-section tempo. |
| Effect commands | 5.3 | The core set (track volume/pan, note volume, maybe, stop track, ticks per line; tempo, break, sample offset, backwards, cut, delay, retrigger, pitch slides, glide, vibrato, tremolo, arpeggio, volume slide, fade in/out). Track width and pan slide were added, effects written beside a delayed note apply to it, and the volume and pan columns take letter commands (glide, slides, fades, backwards, cut). Missing: envelope control, ghost notes, most of the Z set. |
| Instruments and playback | 8.3 | Multiple samples per instrument with key and velocity zones, NNA modes, base note and fine tune, forward/reverse/ping-pong loops, volume/pan/pitch/cutoff envelopes with a hold point, per-instrument filter, per-note effects. Phrases (own speed, columns, loop region, key-mapped and transposed). Instruments can also send MIDI notes. Per-note LFOs (volume, pan, pitch, cutoff), key tracking and velocity-to-cutoff. Stepper and smooth-random modulators, key/velocity/macro routings, envelope loops and fade-out. Instrument drive (also an LFO/macro target), per-instrument FX chains, phrase program mode and shuffle, loop release, a no-interpolation mode, and an instrument bank (.trki, .xrni) were added. Missing: oversampling. Sinc playback is band-limited for pitch-ups and CLAP instrument plugins can be an instrument. |
| Sample editor | 7.9 | Zoomable waveform, selection, cut/copy/paste/delete/crop, silence, fades, gain, normalize, invert, DC removal, reverse, mono/stereo, tape pitch shift, resample, slicing with split-to-keys, loop editing, export to WAV/FLAC/Ogg/MP3/AAC/Opus, import of WAV/AIFF/FLAC/OGG/MP3, live recording. Also spectrum view, loop crossfade, dither, time-stretch, transient slicing and beat sync. Drawing in the waveform, pitch shifting that keeps the length or the formants, and loop release were added. Missing: formant-preserving time stretch. |

Forty-four native devices (comb filter, flanger, pitch shifter, saturator, transient shaper, track delay, auto filter, maximizer, analog filter, mid/side, convolver, key/velocity trackers, meta mixer, formula, send marker among them; gainer, filter, ladder filter, 3- and 10-band EQ, gate, compressor, limiter, delay, reverb, chorus/flanger, phaser, distortion, bit crusher, ring mod, stereo width, tremolo/auto-pan, exciter, plus LFO and envelope-follower modulators) against Renoise's roughly fifty, and local CLAP effect plugins. Groups and sends work (nested groups, pre/post-fader feeds). A sidechain compressor exists, a track delay device and plugin delay compensation (sequencer tracks only) were added. Missing: general sidechain taps, arbitrary routing, some devices. |
| Automation and modulation | 6.6 | Per-pattern lanes for track volume/pan and any native device parameter with a graph editor and playhead. Plugin parameters can be automated too. LFO and envelope-follower devices drive any parameter in the same chain (control rate, one block of delay). Lanes now have curve shapes, range tools (copy, paste, clear, flip, reverse, scale, shift), and tempo and lines-per-beat targets; instrument envelopes have curve shapes, flip, reverse, scale and copy/paste. Missing: recording knob moves, cross-track modulation targets. Hydra and a tempo-synced LFO exist. |
| Plugin hosting | 4.9 | Local CLAP effects and instruments (mono/stereo): scan, add to a track or instrument, sliders, automation, saved with the song (including the plugin's own state), floating plugin windows with host timers and fds, parameter changes made in the window flow back to the sliders, used in offline render; tested against a real shared library with a synth, window, timer and state. Real third-party plugins and windows are untested. Plugins report latency and the other tracks are delayed to match. Missing: embedded windows, sidechain, VST2/VST3/LV2/AU, sandboxing. |
| MIDI, OSC, scripting | 7.0 | MIDI input for notes, CC7/CC10 and transport; MIDI output per instrument with program change; MIDI clock and start/stop master with a latency setting; sandboxed Lua 5.4 scripting (song, patterns, cells, selection, undoable runs, console, user script folder). MIDI clock input follows an external tempo; MIDI learn maps controllers to faders, device parameters and commands; OSC server for transport, mixer, devices and notes; the Lua API reaches instruments, tracks, devices and automation. Pitch bend is mapped. OSC feedback sends state to a control surface; scripts can read and write sample audio and run on load, save, play and stop hooks. Missing: script menu entries, observers while playing. |
| File formats and project | 6.8 | Native `.trkr` roundtrip, export to WAV/FLAC/Ogg Vorbis/MP3/AAC/Opus with a quality scale up to lossless or the codec maximum, a render rate up to 192 kHz and dither, song bounce to sample, `.xrns` import of metadata, tracks, patterns, notes, sequence and instruments with sample audio (no envelopes, devices or automation; element names and sample paths are from memory and only tested against synthetic fixtures, so real-world files may import differently). Autosave with crash recovery and a recent-files list work. `.xrns` export (metadata, tracks, patterns, sequence, instruments with 24-bit samples; roundtrip-tested through the importer; envelopes, devices, automation, phrases and routing are not exported and are reported). `.s3m` and `.xm` import; backups on save; per-track stem and loop-range export in every format. `.xrni` and native `.trki` instrument files, Impulse Tracker import, per-pattern render and export tags were added. Missing: `.xrnt` presets, M4A container. The `.xrni` and `.it` readers were only tested against files our own code builds. |
| Interface and workflow | 6.6 | Native GUI with menus showing shortcuts, context menu, mouse selection, continuous scrolling pattern view, dockable mixer/devices/automation/instrument panels, help window with effect table. Preferences are stored (octave, step, follow, recents). Themes, scale, font size, custom UI and pattern fonts, and a rebindable keymap exist. Command palette, remembered window size and bottom panel. A Renoise-style keymap preset, session restore and backups exist. Missing: accessibility options, embedded plugin windows. |
| Engine quality and reliability | 5.8 | Real-time-safe design, sample-accurate delay column, tick timing, smoothing against clicks, seeded fuzz tests, CPU/voice meter. Sinc playback is band-limited for pitch-ups; Preferences > Audio picks host, devices, sample rate (to the device maximum) and buffer size and restarts live; JACK builds behind a feature; pitch bend. Finished voices are freed on the UI thread, there are 512 voices and 128 tracks, runaway filters recover instead of reaching the output, and the random-song tests cover the new features (they found a NaN phrase-shuffle bug and the filter runaway). Weak spots: no PipeWire-native backend, no oversampling, everything unverified on real hardware. |

## Overall

**About 6.9 / 10 weighted by what a typical Renoise song uses day to day** (pattern editing, instruments,
sample editing, mixing and effects count most; plugins, scripting and format breadth count less). In plain
terms: trakr can already be used to sketch and finish simple sample-based tracker songs on Linux, and its
sample editing and pattern workflow are the closest to Renoise. It cannot yet replace Renoise for anyone who
depends on VST/LV2 plugins or proven third-party CLAP plugins, a full effect rack, or opening existing Renoise projects faithfully.

## Highest-value gaps, in order

1. **Verify against the real thing** (needs files, hardware or the manual that this environment does not have): `.xrns` import and `.xrni`/`.it` readers against real files, then envelopes, devices and automation in `.xrns`; the effect and column-command ids against Renoise; real audio devices, latency, JACK/PipeWire, MIDI keyboards, real third-party CLAP instruments and plugin windows, long-session soak tests.
2. **VST3/LV2 hosting and embedded plugin windows** (large, and untestable without real plugins here).
3. **Envelope control commands, pattern jump commands, per-section tempo.**
4. **Routing**: arbitrary track outputs, general sidechain taps, compensation for groups and sends, post-fader chains.
5. **Oversampling, more filter types, one-shot and sustain loops, recording knob moves and envelopes from the UI or MIDI.**
6. **Formant-preserving time stretch, `.xrnt` track presets, M4A export.**
7. **Track collapse/move and line highlight settings in the pattern editor; accessibility options.**
